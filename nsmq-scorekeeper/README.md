# QuizScore — NSMQ Score Manager

A responsive, standalone static website for recording two-contestant NSMQ-style quiz scores by subject.

## Features
- Physics, Chemistry, Biology and Mathematics scorecards
- Separate scoring entries for each contestant and round
- Correct, bonus, wrong and penalty actions with editable point values
- Live subject totals, overall leaderboard and answer history
- Delete individual scoring events to correct mistakes
- CSV export and local browser storage
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a modern browser. No build step or server is required.

Data is stored in the browser's local storage on the device being used. Use Export CSV to keep a separate copy of results.
